> 但法语发音**有严格规则、几乎没有例外**（比英语规矩多了）——

## 🗺️ 学习路径

```
第 1–2 周   ① 发音规则（头两周只攻这个，务必啃透）
第 3–8 周   ② 语法框架 + ③ 高频短语（每天 1 个语法点 + 5 句跟读）
第 2 个月起  ④ 沉浸：InnerFrench 每天一集 + RFI 慢速新闻
持续        法剧/香颂当甜点，找语伴开口
```

## 🎧 随手听音三件套

1. **[Forvo 法语](https://zh.forvo.com/languages/fr/)** —— 任何词的母语者真人发音；
2. **有道词典 App / 法语助手** —— 手机查词点喇叭就能听；
3. **[YouGlish 法语](https://youglish.com/french)** —— 听单词在真实视频里的读法。

## ⚠️ 法语专属提醒

1. **发音规则先行**：这是法语唯一「前置硬门槛」，掌握后阅读能力突飞猛进；
2. **变位别硬背全表**：先吃透 être/avoir/aller + -er 规则动词，其余用到再查；
3. **阴阳性伴词记**：记名词永远连着 le/la 一起；
4. **接受入门陡**：第一个月最痛苦，熬过去就是坦途——三门语言里法语「后期加速」最明显。
