# 🔊 法语发音完全教程：规则一旦掌握，见词能读

> 法语发音和英语最大的不同：**规则严格、几乎没有例外**。
> 这章把规则一次讲全。每个例词都建议听真人读：
> [Forvo 法语](https://zh.forvo.com/languages/fr/)（母语者录音）、**有道词典 App**（查词点喇叭）、
> [YouGlish 法语](https://youglish.com/french)（听真实视频里怎么读）。

## 一、总原则：三条铁律

1. **重音永远在最后一个音节**——不用记重音位置，法语没有这个烦恼；
2. **词尾辅音一般不发音**：Paris 读「巴黎」不读「巴黎斯」。例外口诀 **CaReFuL**——词尾是 **C、R、F、L** 的通常要发音（avec、pour、chef、mal）；
3. **e 在词尾不发音**：table 读 /tabl/，madame 读 /madam/。

## 二、元音字母组合（法语发音的主战场）

法语单个字母不可怕，可怕的是组合——好在组合读音是固定的：

| 组合 | 发音 | 例词（去 Forvo 听） |
| --- | --- | --- |
| **ou** | /u/（乌） | bonjour（你好）、vous（您） |
| **u** | /y/（ü，嘴唇圆说「衣」） | tu（你）、salut（嗨）⚠️ 中文母语者福利：就是拼音 ü |
| **oi** | /wa/（哇） | moi（我）、trois(三) |
| **au / eau** | /o/（欧） | beau（美）、eau（水） |
| **ai / ei** | /ɛ/（哎） | maison（房子）、j'aime（我喜欢） |
| **eu / œu** | /ø/（额，圆唇） | deux（二）、sœur（姐妹） |
| **é** | /e/（闭口「诶」） | café、été（夏天） |
| **è / ê / e+双辅音** | /ɛ/（开口「哎」） | père（父亲）、être（是） |
| **oy / ay** | /waj/ /ɛj/ | voyage（旅行） |

## 三、鼻化元音：法语的招牌（4 个）

发音要领：元音 + 鼻腔共鸣，**n/m 本身不发音**，只是「鼻化信号」。

| 组合 | 发音 | 例词 |
| --- | --- | --- |
| **an / en / am / em** | /ɑ̃/（昂） | France、enfant（孩子）、temps（时间） |
| **on / om** | /ɔ̃/（翁） | bon（好）、nom（名字） |
| **in / im / ain / ein / un** | /ɛ̃/（安，扁嘴） | vin（酒）、pain（面包）、un（一） |
| **ien** | /jɛ̃/（衣安） | bien（好）、combien（多少） |

> 自查：发鼻化元音时捏住鼻子，声音应该明显变化。去 Forvo 听 bon / bain / banc 三个词对比。

## 四、辅音要点（只讲和英语/拼音不同的）

| 字母 | 规则 | 例词 |
| --- | --- | --- |
| **r** | 小舌音：像轻轻漱口/清嗓子的摩擦音 | Paris、merci。练法：含少量水仰头漱口找位置；说成英语 r 或拼音 h 也能被听懂，别卡在这 |
| **h** | 永远不发音 | homme（男人）读 /ɔm/ |
| **c** | c+a/o/u 读 /k/；c+e/i 读 /s/；ç 永远 /s/ | café、cinéma、français |
| **g** | g+a/o/u 读 /g/；g+e/i 读 /ʒ/（如「日」） | gare（车站）、rouge（红） |
| **ch** | /ʃ/（嘘） | chat（猫）、chercher（找） |
| **gn** | /ɲ/（尼） | montagne（山） |
| **qu** | /k/ | qui（谁）、musique |
| **ill** | 通常 /j/（衣） | fille（女孩）读 /fij/ |
| **s** | 两元音之间读 /z/ | maison /mɛzɔ̃/ |

## 五、联诵（Liaison）与省音（Élision）

- **联诵**：前词的哑音尾辅音 + 后词元音开头 → 连起来读。
  - vous êtes（你们是）→ 读 vou-**z**êtes；petit ami → peti-**t**ami
  - 初期只需记住高频组合（les amis、vous avez、c'est un），其余靠听多了自然会；
- **省音**：je/le/la/ne/de/que + 元音开头的词 → 缩写。
  - je aime → **j'aime**；le ami → **l'ami**；ce est → **c'est**

## 六、跟读训练法（两周计划）

```
第 1–3 天   字母表 + 元音组合表（每天 20 分钟，Forvo 逐词听）
第 4–6 天   鼻化元音专项（bon/bain/banc 对比 + 例词跟读）
第 7–9 天   辅音要点 + CaReFuL 规则（拿 bonjour/merci/salut 练）
第 10–14 天 整句跟读：把「高频短语」章的句子逐句听读模仿
```

- 每天选 10 个词 → Forvo 听 3 遍 → 跟读 3 遍 → 录音对比 1 遍；
- 检验标准：看到 `croissant`、`restaurant` 这类生词能按规则读个八九不离十。
