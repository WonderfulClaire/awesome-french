# 🗣️ 法语高频短语与数字：开口就用这章

> 每句都去 [Forvo](https://zh.forvo.com/languages/fr/) 或有道词典听真人读，**跟读到不看拼写也能说**。
> 中文谐音只帮你迈出第一步，鼻化元音和小舌音必须听原声校准。

## 一、保命十句（先背这页）

| 法语 | 意思 | 读音提示 |
| --- | --- | --- |
| Bonjour ! | 你好/日安（白天万能） | 蹦如尔 |
| Bonsoir ! | 晚上好 | 蹦斯瓦 |
| Merci (beaucoup) ! | （非常）感谢 | 梅尔西（伯库） |
| S'il vous plaît | 请/劳驾（点单必备） | 西勒-乌-普莱 |
| Pardon / Excusez-moi | 抱歉/借过/打扰 | 巴红 / 埃克斯屈泽-姆瓦 |
| Oui / Non / Ça va | 是 / 否 / 还行 | 威 / 农 / 撒瓦 |
| Je ne comprends pas | 我不明白 | 熟讷孔普宏巴 |
| Parlez plus lentement, s'il vous plaît | 请说慢一点 | 帕嘞-普吕-隆特芒 |
| Je ne parle pas bien français | 我法语说得不好 | —— |
| Au revoir ! | 再见 | 欧赫瓦 |

## 三、数字：法语最「臭名昭著」的部分

### 0–20（硬背）

| 0–10 | zéro un deux trois quatre cinq six sept huit neuf dix |
| --- | --- |
| 11–16 | onze douze treize quatorze quinze seize |
| 17–19 | dix-sept dix-huit dix-neuf（17=10+7 开始有规律） |
| 20 | vingt |

### 整十 + 著名的「法式数学」

| 数 | 法语 | 逻辑 |
| --- | --- | --- |
| 30/40/50/60 | trente / quarante / cinquante / soixante | 正常 |
| **70** | soixante-dix | 60+10 🤯 |
| **80** | quatre-vingts | 4×20 🤯 |
| **90** | quatre-vingt-dix | 4×20+10 🤯 |
| 21 | vingt et un | 20 和 1 |
| 99 | quatre-vingt-dix-neuf | 4×20+10+9 |

> 初期只要能听懂价格就行。听力技巧：听到 soixante 先别急着写 6，等后面有没有 -dix。

## 四、点餐 / 咖啡馆（法国日常核心场景）

| 法语 | 意思 |
| --- | --- |
| Une table pour deux, s'il vous plaît. | 两个人的位子，谢谢。 |
| La carte / Le menu, s'il vous plaît. | 请给我菜单。 |
| Je voudrais un café / un croissant. | 我想要一杯咖啡/一个可颂。（Je voudrais = 礼貌版「我想要」，点单万能开头） |
| Qu'est-ce que vous me conseillez ? | 您有什么推荐？ |
| L'addition, s'il vous plaît ! | 买单！ |
| C'était délicieux ! | 太好吃了！ |

## 五、问路 / 购物 / 交通

| 法语 | 意思 |
| --- | --- |
| Où est … ? / Où sont les toilettes ? | ……在哪？/ 洗手间在哪？ |
| C'est loin d'ici ? | 离这儿远吗？ |
| à gauche / à droite / tout droit | 左转 / 右转 / 直走 |
| C'est combien ? / Ça coûte combien ? | 多少钱？ |
| C'est trop cher ! | 太贵了！ |
| Je peux payer par carte ? | 能刷卡吗？ |
| Un billet pour ___, s'il vous plaît. | 一张去 ___ 的票。 |

## 六、星期与时间（听懂约会安排）

- 星期：lundi 一 · mardi 二 · mercredi 三 · jeudi 四 · vendredi 五 · samedi 六 · dimanche 日
- aujourd'hui 今天 · demain 明天 · hier 昨天
- Quelle heure est-il ? 现在几点？ — Il est trois heures. 三点。

## 七、日常反应词（让你听起来像会法语）

| 法语 | 场景 |
| --- | --- |
| D'accord ! | 好的/同意（≈OK，法国人口头禅） |
| Bien sûr ! | 当然！ |
| C'est bon. | 行了/没问题/好吃（万能） |
| Pas de problème. | 没问题 |
| Voilà ! | 给你/就是这样（递东西、总结都能用） |
| Bon appétit ! | 用餐愉快（开饭必说） |
| Bonne journée ! | 祝你今天愉快（告别加分项） |
